# 独立探索实验

尚未确定纳入正式方法的工作放在 `experiments/<主题>/`，例如冻结身体探针、离线机制分析。正式训练、推理和功能开发继续使用现有 RHSCI 框架；具体约定见[开发边界](../docs/DIRECTORY_STRUCTURE.md#development-boundaries-20261103)。

- 每个主题有自己的 README，说明目的、入口、配置和已验证/待验证范围。
- 通过现有接口调用 `src/` 中的模型、处理器及训练/推理工具，复用公共函数，不复制整套骨干或训练器。
- 正式包和默认入口不依赖本目录；实验确定纳入后，在对应模型 `rhsci/` 或公共 `src/rhsci/` 中接入。
- 数据、模型、环境、缓存和运行输出放在仓库外，使用显式路径；实验代码和小配置可放在本目录。

当前仅建立目录约定，没有迁入或执行 PSI0-RAW 的历史实验。
